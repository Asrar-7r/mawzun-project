# المسرد (مصطلحات موزون)

| المصطلح | English | التعريف |
| --- | --- | --- |
| موزون | Mawzun | اسم المنصة؛ يعني المتوازن المتناسق، ويعبّر عن التوازن الدلالي |
| طبقة الأمان الدلالي | Semantic Guard | طبقة ضبط تضمن مطابقة مخرجات النماذج للقيود الشرعية |
| الانزياح الدلالي | Semantic Drift | انحراف المعنى المقاصدي رغم سلامة الصياغة اللغوية |
| القيود الدلالية | Semantic Guardrails | محددات صارمة يلتزم بها النموذج بعد اعتمادها |
| كائن المعرفة | Knowledge Object | تمثيل بنيوي للمعنى المستخلص (موضوع، فكرة، أثر) |
| المتن / السند | Matn / Sanad | متن الحديث وسلسلة رواته |
| المقاصد | Maqasid | الأغراض والغايات الشرعية للخطاب |
| النية | Niyyah (Intention) | القصد القلبي الباطن؛ مناط صحة العمل وقبوله |
| العلة والمعلول | Cause & Effect | العلاقة السببية بين العمل وقصده |
| مانع الهلوسة | Hallucination Guard | قيد يمنع إقحام معانٍ أو تفريعات لم ينطق بها الأصل |
| بوابة الاعتماد البشري | Human Approval Gate | مراجعة إلزامية قبل تفويض النموذج |
| السلسلة الدلالية | Semantic Pipeline | مسار المراحل الست من الإدخال حتى النتيجة |

## مصطلحات تقنية

| المصطلح | التعريف |
| --- | --- |
| App Router | موجّه التطبيق في Next.js 16 المعتمد على المجلدات |
| Server Component | مكوّن يُنفَّذ على الخادم افتراضياً بلا جافاسكربت للعميل |
| `@theme` | كتلة Tailwind v4 لتعريف رموز التصميم كمتغيّرات CSS |
| `StageNav` | شريط الإجراءات الذي يختم كل شاشة مرحلة |
| مصدر الحقيقة | ملف واحد مرجعي (`stages.ts`) تُشتق منه كل الواجهات |

راجع [مسار التدقيق](/docs/workflow/audit-pipeline) و[الحماية الدلالية](/docs/workflow/semantic-guard)
لسياق استخدام هذه المصطلحات.
