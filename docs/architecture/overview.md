# النظرة المعمارية العامة

**موزون** منصة حوكمة دلالية تهدف إلى ضمان أن مخرجات نماذج الذكاء الاصطناعي التوليدية
حين تتعامل مع المحتوى الإسلامي تبقى مطابقة للقيود الشرعية المعتمدة، فلا تُحدث حيوداً
(انحرافاً) في المعنى المقاصدي.

## المبادئ المعمارية

1. **مصدر حقيقة واحد للمراحل** — ملف `src/lib/stages.ts` يوحّد تسميات المراحل وترتيبها،
   فيستحيل أن ينحرف التنقّل عن التوجيه.
2. **الفصل بين الهيكل والمحتوى** — `layout/` للهيكل الثابت، `stages/` لمنطق كل مرحلة،
   `ui/` للعناصر المحايدة.
3. **RTL أولاً** — الاتجاه الجذري `dir="rtl"`، والتخطيط مرآتي بالكامل. راجع [ADR-0002](/docs/adr/0002-rtl-first).
4. **رموز تصميم مركزية** — كل الألوان والطباعة والمسافات معرّفة في `globals.css` عبر `@theme`، بلا قيم مبعثرة.
5. **Server Components افتراضياً** — لا `"use client"` إلا عند الحاجة لتفاعل فعلي.

## الطبقات

```text
┌──────────────────────────────────────────────────────────┐
│  App Router (src/app)                                     │
│  layout.tsx → AppShell (Sidebar + TopBar)                 │
│  صفحات المراحل: 01-input → 04-transformation             │
│  مركز التوثيق: /docs                                       │
├──────────────────────────────────────────────────────────┤
│  المكوّنات (src/components)                               │
│  layout/  ·  stages/  ·  docs/  ·  ui/                     │
├──────────────────────────────────────────────────────────┤
│  المنطق المشترك (src/lib)                                 │
│  stages · typography · cx · docs                           │
├──────────────────────────────────────────────────────────┤
│  نظام التصميم (globals.css @theme)                        │
│  ألوان · طباعة · مسافات · أنصاف أقطار                      │
└──────────────────────────────────────────────────────────┘
```

## تدفّق البيانات الدلالي

يمرّ المحتوى عبر مسار من ست مراحل: **الإدخال ← التحليل ← القيود ← التحويل ← الفحص ← النتيجة**.
كل مرحلة تُنتج «كائن معرفة» (Knowledge Object) يتغذّى منه ما بعده. راجع
[سير عمل التدقيق](/docs/workflow/audit-pipeline) للتفاصيل، و
[مبدأ الحماية الدلالية](/docs/workflow/semantic-guard) لفلسفة الضبط.
